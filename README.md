# NBA Draft Combine Exploratory Data Analysis

This project explores NBA Draft Combine data using Python, Pandas, and Matplotlib. The goal of this analysis was to investigate player measurements, athletic performance, and positional trends through exploratory data analysis (EDA).

## Dataset

- Source: NBA Draft Combine dataset from Kaggle
- File used: `draft_combine_stats.csv`

## Research Questions

1. How many players participated in the combine by position?
2. What is the average weight of centers, and how does it compare to the average combine player?
3. What is the relationship between height and weight among combine players?
4. Is there a correlation between wingspan and maximum vertical leap?
5. Which guards qualify as elite athletes based on vertical leap, standing reach, and wingspan percentile rankings?
6. Who were the tallest and heaviest players in each combine season?

## Key Findings

- Power forwards and guards were the most common positions represented in the combine dataset.
- Centers were significantly heavier than the average combine player.
- Height and weight showed a strong positive relationship.
- Wingspan and maximum vertical leap showed weak correlation.
- Only a small number of guards met elite athletic thresholds across multiple measurements.
- Frontcourt players frequently appeared as the tallest and heaviest prospects each season.
